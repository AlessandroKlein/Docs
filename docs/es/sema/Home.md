# SEMA

> **Tipo:** Embebidos (ESP32) | **Estado:** En desarrollo | **Fecha:** 2026-10-03 | **Firmware:** v0.37.0

Sistema de Estación Meteorológica Autónoma: plataforma modular para construir
estaciones meteorológicas y ambientales basada en **ESP32**, configurable por
**interfaz web** sin recompilar el firmware.

## Principio

> El hardware define las capacidades; la configuración web define cómo se utilizan.
