# Glosario

> **Tipo:** Referencia | **Estado:** Estable | **Fecha:** 2026-10-02

- **ESP32**: microcontrolador que lee sensores y activa actuadores.
- **GPIO / pin**: las entradas/salidas del ESP32.
- **NVS**: memoria que guarda la configuración aunque se corte la energía.
- **I²C / SPI / 1-Wire / RS485 / CAN**: buses para conectar sensores/expansores.
- **MQTT**: protocolo simple para enviar mensajes (como un chat).
- **OTA**: actualizar el firmware por red, sin cables.
- **Rollback**: volver a la versión anterior si una actualización falla.
- **Token de API**: "contraseña de máquina" para que el servidor envíe órdenes.
- **Health monitor**: vigilancia de que cada tarea interna siga respondiendo.
- **W5500**: chip Ethernet (SPI) para conectarse por cable.
