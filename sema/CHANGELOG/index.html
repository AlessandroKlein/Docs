    changelog sema

    Tipo: Referencia | Estado: Estable | Fecha: 2026-10-08 | Firmware: v1.103.0

    Historial completo de versiones del firmware SEMA, espejado del repositorio de código (CHANGELOG.md). Cada release tiene su tag vX.Y.Z y su release en GitHub. Para el detalle por archivo ver Registro de cambios; para las convenciones de numeración, Versionado.

    Registro de versiones (CHANGELOG)

    Todos los cambios relevantes de este proyecto se documentan en este archivo.

    El formato sigue Keep a Changelog y el proyecto adhiere a Versionado Semántico. Ver también Versionado.

    1.103.0 - 2026-10-08

    Changed

    • MAX14830 muestra sus 4 puertos UART (U0-U3) seleccionables.

    1.102.0 - 2026-10-08

    Removed

    • Carpeta data/ eliminada; gridstack guardado en docs/Optimizacion web/ y servido desde PROGMEM.
    • onStaticFile y dependencia LittleFS del servidor web eliminadas.

    1.101.0 - 2026-10-08

    Added

    • Selector de bus I2C en sensores (nativo o SC18IS602B).
    • Selector UART en sensores/modulos (GPIO o MAX14830) para Zigbee y Modbus.

    1.100.0 - 2026-10-08

    Changed

    • gridstack (CSS/JS) embebido en PROGMEM y servido con gzip (Content-Encoding), sin depender de LittleFS.

    1.99.0 - 2026-10-08

    Fixed

    • MCP23S17 y expansores SPI (MAX14830/SC18IS602B) mostrados con su CS en Pines de buses.

    1.98.0 - 2026-10-08

    Added

    • Expansores SPI: MAX14830 (UART por SPI) y SC18IS602B (I2C por SPI), cantidad libre, solo configuran CS.

    1.97.0 - 2026-10-08

    Changed

    • Pines reservados se muestran deshabilitados como ocupado (no se ocultan).
    • SPI de WROOM movido a 14/12/15 para no chocar con Ethernet RMII; LoRa RST a 32.

    1.96.0 - 2026-10-08

    Changed

    • I2C con boton de guardado propio que reinicia el dispositivo al cambiar SDA/SCL.

    1.95.0 - 2026-10-08

    Changed

    • Pines SPI (SCK/MISO/MOSI) mostrados y reservados.
    • Ethernet RMII reservado solo cuando esta habilitado.

    1.94.0 - 2026-10-08

    Added

    • Pines de buses editables: habilitar/deshabilitar modulos (Modbus/CAN/LoRa/Zigbee/Ethernet), seleccionar CS (SPI) e I2C (SDA/SCL).
    • Chip-select de microSD movido a Pines de buses.

    1.93.0 - 2026-10-08

    Fixed

    • Pines del MCP23S17 configurados como entrada/salida quedan reservados (no se pueden usar como CS de otros chips).

    1.92.0 - 2026-10-08

    Changed

    • Seccion General separada de NTP (unidades/idioma).
    • Chip-select de microSD como dropdown de pines.
    • Pines de buses solo reservan si el elemento esta habilitado.
    • Demo: MCP23S17 conectado (CS=5) con 16 salidas.

    1.91.0 - 2026-10-08

    Added

    • MCP23S17 como expansor: sus 16 pines (A0-B7) se agregan a los selectores de pines cuando esta habilitado.

    1.90.0 - 2026-10-08

    Added

    • Modales personalizados (reemplazan confirm()/alert()).

    1.89.0 - 2026-10-08

    Fixed

    • Pines reservados por hardware (Ethernet RMII) no aparecen en los selectores de pines.
    • Defaults de Zigbee (18/19) y LoRa CS (10) corregidos para no solaparse.

    1.88.0 - 2026-10-08

    Changed

    • CSS mas pulido (transiciones, foco, sombras, modal con blur y animacion).
    • Pines ocupados aparecen deshabilitados (no se pueden seleccionar).

    1.87.0 - 2026-10-08

    Removed

    • Pie de tarjeta (sensor_id · quality) eliminado del dashboard.

    1.86.0 - 2026-10-08

    Changed

    • Nombres de tarjetas en espanol con tooltip (?).
    • Mas cadenas traducidas (botones y nav).

    1.85.0 - 2026-10-08

    Changed

    • /config/network separado: WiFi y mDNS con botones de guardado independientes.
    • Etiqueta de temperatura aclarada (Temp chip, interna).

    1.84.0 - 2026-10-08

    Fixed

    • Datos WiFi (SSID/IP/mDNS) no aparecian: el JSON de /api/v1/system era demasiado chico y descartaba esos campos.

    1.83.0 - 2026-10-08

    Fixed

    • Temperatura interna del ESP corregida (-10 C aproximado).

    Added

    • Toggle mDNS en /config/network (funciona con el flag config.network.mdns).
    • Estilo del boton ojo de contrasena y de configuracion avanzada.

    1.82.0 - 2026-10-08

    Added

    • Boton ojo para ver contrasena WiFi y config avanzada (IP/gateway/mascara/DNS) plegable.
    • Datos WiFi (SSID, IP, mDNS) en /config/system.
    • Bus I2C compartido (SDA/SCL) como elemento unico; pines unicos sin repetir (PIN/RX/TX/CS).

    1.81.0 - 2026-10-08

    Added

    • Demo con magnitudes derivadas (rocio, indice de calor, QNH, VPD, AQI, etc).
    • Datos del ESP en /config/system: temperatura interna, reinicios y motivo de reset.

    1.80.0 - 2026-10-08

    Added

    • Selectores de pines GPIO: solo muestran pines libres y una opcion sin asignar.

    1.79.0 - 2026-10-08

    Changed

    • Demo mas completa: agrega bateria, radiacion solar, PM10 y rafagas de viento.

    1.78.0 - 2026-10-08

    Fixed

    • Demo: al cambiar unidades se convierten los valores numericos (no solo la etiqueta).

    1.77.0 - 2026-10-08

    Changed

    • Menu unificado (dashboard y config usan el mismo nav) y traduccion de titulos de seccion (es/en).

    1.76.0 - 2026-10-08

    Fixed

    • Guardado de config: NVS sin espacio. Se quito el respaldo config_bak y se agrego recuperacion automatica (limpiar y reintentar).

    1.75.0 - 2026-10-08

    Added

    • Multi-idioma es/en en la navegacion y selector de idioma en /config/system.

    1.74.0 - 2026-10-08

    Fixed

    • Tema claro/oscuro ahora funciona en todas las paginas de configuracion (faltaba incluir kThemeJs).

    1.73.0 - 2026-10-07

    Added

    • Selector de unidades (metrico/imperial) en /config/system.

    1.72.0 - 2026-10-07

    Added

    • Paginas por seccion: /sensors (lecturas en vivo) y /events (eventos).

    1.71.0 - 2026-10-07

    Removed

    • Seccion Salidas/entradas GPIO de /config/sensors.

    1.70.0 - 2026-10-07

    Added

    • Agregacion por niveles del historico: promedios horarios de lo mas viejo (serie /api/v1/history?series=aggregated).

    1.69.0 - 2026-10-07

    Changed

    • Registros de desplazamiento (cascada) deshabilitados por defecto (flag SEMA_USE_SHIFT, beta).

    1.68.0 - 2026-10-07

    Added

    • microSD (SPI) configurable desde la web: habilitar/deshabilitar + chip-select.
    • Historico guardado en microSD; sin SD las graficas quedan vacias (sin gastar memoria interna).

    1.67.0 - 2026-10-07

    Added

    • Watchdog jerarquico por tarea: cada tarea late con su timeout y se expone en /api/v1/health.

    1.66.0 - 2026-10-07

    Changed

    • Pines de buses por board: Ethernet RMII (WROOM) vs W5500 SPI (S3).
    • MicroSD documentada por SPI (no SDMMC) con su chip-select.

    1.65.0 - 2026-10-07

    Added

    • Zona horaria en timestamps (configTzTime + epoch local).
    • Config fail-safe: respaldo config_bak y restauracion automatica.

    1.64.0 - 2026-10-07

    Added

    • Registros de desplazamiento en cascada: agregar varios 74HC595/74HC165, cada uno con LATCH y sus 8 pines.
    • Tooltips (?) de expansores con tipo de datos y voltajes.

    1.63.0 - 2026-10-07

    Changed

    • Ethernet LAN8720A: pines RMII oficiales Espressif documentados en HwProfile y visibles en Pines de buses.

    1.62.0 - 2026-10-07

    Changed

    • MCP23017 -> MCP23S17 (SPI) con CS y configuracion de los 16 pines.
    • Registro de desplazamiento: usa MOSI/SCLK del bus SPI y solo LATCH por chip.

    1.61.0 - 2026-10-07

    Changed

    • Expansores separados: MCP23017 (direccion), 74HC595/74HC165 (tipo+pines) y GPIO, cada uno con su entrada.

    1.60.0 - 2026-10-07

    Changed

    • ADS1115: el canal A0-A3 se elige desde cada sensor analogico (FUENTE=ADS1115), no desde el chip.

    1.59.0 - 2026-10-07

    Added

    • ADS1115: canal A0-A3 y magnitud (que mide) configurables.

    1.58.0 - 2026-10-07

    Added

    • DS18B20: lectura por direccion ROM (getTempC por DeviceAddress).

    1.57.0 - 2026-10-07

    Changed

    • DS18B20: un unico pin de bus 1-Wire y direccion ROM por sensor.

    1.56.0 - 2026-10-07

    Added

    • Fuente ADC (ESP32 nativo o ADS1115) para sensores analogicos.
    • Multiples DS18B20 (agregar/eliminar con nombre).

    1.55.0 - 2026-10-07

    Changed

    • Sensores especificos: Veleta, Bateria, Anemometro y Pluviometro (cada uno con su entrada/canal).

    1.54.0 - 2026-10-07

    Changed

    • Sensores con descripcion (tooltip ?) y nombres aclarados (veleta, pluviometro, anemometro).

    1.53.0 - 2026-10-07

    Fixed

    • Switches de sensores (toggle) ahora conmutan (label).

    Added

    • Seccion Expansores y salidas: registro 74HC595/74HC165 + GPIO (nativo o MCP23017).
    • Endpoint POST /api/v1/config/io.

    1.52.0 - 2026-10-07

    1.0.0 - 2026-10-04

    Primera versión estable

    Base completa de SEMA, lista para su alcance principal:

    • Core modular: SemaCore, EventBus, ConfigManager (schema=1), Storage (NVS + LittleFS), Scheduler, CapabilityManager, Watchdog, HealthMonitor, PowerManager.
    • Sensores (12 tipos / 5 interfaces): I²C (BME280, BMP280, SHT40, SHT31, AHT20, BH1750, VEML6075, SCD30), 1-Wire (DS18B20 multi-dispositivo), ADC, PCNT (lluvia/viento), UART (PMS5003). Catálogo configurable por factoría (D-0042) y Board Profile (D-0050) para PCBs.
    • Datos: flujo MEDIR→VALIDAR→PROCESAR→ALMACENAR→PUBLICAR, derivadas (punto de rocío, índice de calor, presión de vapor, humedad absoluta), histórico con rotación y NTP/RTC (epoch UTC).
    • Web/API: dashboard con login por sesión, REST /api/v1 completa, WebSocket, eventos/alarmas persistentes.
    • Operación: OTA con rollback, mDNS, reconexión WiFi, energía (deep sleep + wake), backup/restore, diagnóstico y Health Monitor.
